# North-west Sydney Rent Explorer

A data analysis and dashboard project exploring weekly rents recorded in NSW
rental bond lodgements.

## Project status

In progress. The first milestone is preparing the source data for analysis.

## Data source

NSW Fair Trading rental bond lodgement data:
https://www.nsw.gov.au/housing-and-construction/rental-forms-surveys-and-data/rental-bond-data

The records describe rents at the start of new tenancies and are grouped by
postcode. Postcodes do not map exactly to suburbs.

## Planned features

- Clean and document the rental bond data
- Compare weekly rent by postcode, month, dwelling type, and bedroom count
- Show the results in an interactive dashboard
